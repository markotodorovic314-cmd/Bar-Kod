BAR-KOD PARTNER PORTAL — DEMO ZA GITHUB PAGES

1. Raspakujte ZIP.
2. Otpremite index.html, favicon.svg i folder assets u koren GitHub repozitorijuma.
3. U GitHub repozitorijumu otvorite Settings > Pages, izaberite Deploy from a branch, pa main i / (root). Sačekajte objavljivanje URL-a.

Kupac: market@demo.bar-kod.com
Admin: admin@demo.bar-kod.com
Lozinka za oba: Demo2026!

Demo podaci, cene, zalihe, porudžbine i ERP Navision su ilustrativni. Izmene u portalu čuvaju se samo u pregledaču posetioca (localStorage); različiti uređaji ne dele podatke. Vizuali brendova se učitavaju sa javne stranice bar-kod.com i zahtevaju internet vezu. GitHub Pages je javno dostupan, a demo login nije prava zaštita pristupa.
